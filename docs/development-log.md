# 개발 단계 기록

각 단계는 로컬 빌드 또는 검사 뒤 한글 커밋 메시지로 기록합니다.

| 단계 | 내용 | 검증 |
| --- | --- | --- |
| 1 | .NET 8 WPF 솔루션, Core 라이브러리, 테스트 프로젝트, 초기 카탈로그 | Core 빌드 |
| 2 | 앱 카탈로그 검증, GitHub 최신 안정 릴리스/ETag 캐시, CPU별 자산 선택, 다운로드 및 체크섬 검증, 설치 메타데이터 | 코어 테스트 44개 통과 |
| 3 | 한글 라이브러리, 검색, 앱 설정, 카탈로그 가져오기/내보내기, 업데이트 상태와 실행 화면 | Release 빌드, 실제 창에서 검색·설정·등록 오류 안내 확인 |
| 4 | 사용자용 포터블 배포 ZIP, 체크섬, Windows CI, GitHub Release 자동화, 설치·사용 안내 | 자체 포함 패키지 실행, 런타임 및 ZIP 검사, 실제 GitHub 조회·다운로드 검증 |

저장소의 실제 초기 작업과 단계별 커밋은 `git log --oneline`에서 확인할 수 있습니다.

모아뷰 릴리스 저장소 주소와 실제 GitHub 자산은 명시적으로 알려지기 전까지 앱 카탈로그에 연결하지 않습니다. 로컬 체크아웃에서 저장소 remote를 확인할 수 없었기 때문입니다.

## 검증 기록 · 2026-11-07

- `dotnet test tests/MoaLauncher.Core.Tests/MoaLauncher.Core.Tests.csproj`: 44개 통과. 잘못된 체크섬, 누락된 실행 파일, ZIP 경로 탈출·심볼릭 링크·과도 압축, 취소, 기존 설치 상태 보존, HTTP 오류·캐시를 포함합니다.
- WPF Release 빌드: 경고 0, 오류 0. 실제 설치된 모아뷰 `0.1.7` 자동 탐지 확인.
- 실제 GitHub 통신: 참고 저장소의 최신 안정 릴리스 조회(200), ETag 재확인(304, 최신 상태), 허용된 리디렉션을 통한 `SHA256SUMS.txt` 다운로드, API digest와 파일 SHA-256 일치 확인. 해당 프로그램을 설치하거나 실행하지 않았습니다.
- 자체 포함 Windows x64 배포: .NET / Windows Desktop `8.0.33`, 카탈로그, 런타임 라이선스, ZIP 및 체크섬 생성.
- 모아뷰의 실제 다운로드·설치·업데이트는 릴리스 저장소가 연결되지 않아 아직 검증하지 않았습니다. GitHub Actions는 구성했으며 원격 실행은 하지 않았습니다.

제한된 개발 환경에서 testhost 프로세스 통신이 차단되어 테스트 실행은 해당 통신을 허용한 환경에서 수행했습니다. 패키지 복원에는 이미 설치된 로컬 NuGet 캐시를 사용했습니다.

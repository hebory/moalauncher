## Windows 자동 실행 설정 · 2026-11-07

- 설정의 ‘시작 및 종료’에 ‘Windows 시작 시 자동 실행’을 추가했습니다. 기본값은 꺼짐이며 현재 사용자 계정의 Run 등록을 켜고 끕니다. 등록 상태를 직접 읽어 설정 파일과 중복 저장하지 않습니다.
- 자동 실행 명령은 현재 실행 파일과 데이터 폴더, `--background` 옵션을 포함합니다. 로그인 시 창을 표시하지 않고 트레이·카탈로그·업데이트 타이머를 초기화하며, 백그라운드 중복 실행도 기존 창을 띄우지 않습니다. 직접 실행할 때는 기존 창을 복원합니다.
- 등록 실패 시 토글을 실제 상태로 복원합니다. 한글·공백·끝 역슬래시 경로를 처리하고, Windows Run 명령 길이 제한 초과 및 dotnet 호스트 등록을 거부합니다.
- 정상 시작/백그라운드 시작 스모크 테스트 모두 통과했습니다. 전용 임시 레지스트리 키에서 등록·재조회·해제·다른 값 보존·명령줄 파싱·오류 시 기존 값 보존을 검증했습니다. 실제 시작 프로그램 등록은 변경하지 않았습니다.
- 실제 Windows 실행에서 `--background` 시작 후 표시된 창 없이 프로세스가 유지되고, 직접 재실행하면 같은 창이 복원되는 것을 확인했습니다. 설정 화면과 명시적 종료도 확인했습니다. Windows 로그아웃·재로그인은 수행하지 않았습니다.
- Release 빌드 경고 0개·오류 0개. Windows CI에 백그라운드 시작 스모크 테스트를 추가했습니다. Windows x64 자체 포함 ZIP을 갱신하고 체크섬 및 ZIP 내부 DLL과 게시 빌드의 일치를 확인했습니다.

- 시작·주기·수동 확인 및 앱 등록 후 확인에서 설치된 프로그램의 새 버전을 발견하면 트레이 알림을 표시합니다. 한 번의 확인에서 여러 앱을 발견하면 하나로 묶습니다. 캐시·확인 오류·미설치·작업 중인 항목은 알림에서 제외합니다.

- 알림 클릭은 창을 복원하고 검색을 비운 뒤 업데이트 목록을 표시합니다. 현재도 업데이트가 가능한 알림 대상은 목록 위쪽에 표시합니다. 읽기 전용 상세 창은 닫고, 편집 창의 미저장 입력은 보존합니다. 알림만으로 설치하지 않으며 기존 업데이트 버튼과 검증된 설치 경로를 사용합니다.
- Release 빌드 경고 0개·오류 0개. 일반 시작·백그라운드 시작 스모크 테스트를 모두 통과했습니다. 가짜 릴리스·설치 서비스를 사용해 알림 묶음, 중복 억제, 캐시·자산 오류 제외, 새 버전 재알림을 검증했습니다.

- Release 빌드 경고 0개·오류 0개, 코어 테스트 101개와 일반/백그라운드 시작 스모크 검사를 통과했습니다. 모의 GitHub 응답으로 비공개 ZIP 최초 설치→업데이트, 직접 다운로드·CDN 리디렉션, 체크섬 보조 파일, 권한 오류, 공유 내보내기 제외와 토큰 미노출을 검증했습니다. Windows 자격 증명의 저장·교체·삭제는 격리된 테스트 대상으로 확인했습니다.
- 별도 검토 데이터로 설정 카드와 개인 앱 배지의 실제 화면을 확인했습니다. 실제 사용자 토큰이나 비공개 저장소로 연결한 검증은 수행하지 않았으며, GitHub 배포와 PC 설치본 업데이트는 이번 변경에 포함하지 않았습니다.

## 프로그램 목록의 그리드 보기 · 2026-11-14

- 검색창 옆에 리스트·그리드 보기 전환을 추가했습니다. 기본값은 기존 리스트이며 선택한 보기를 사용자 설정에 저장하고 다음 실행에서 복원합니다. 보기 변경과 업데이트 설정 변경이 서로의 값을 덮어쓰지 않도록 같은 저장 경로를 사용합니다.
- 그리드는 기존 커버·아이콘과 설치 버전, 설명, 상태, 설치·실행·업데이트 및 상세 보기 버튼을 표시합니다. 커버가 없거나 비공개 앱이면 색상 배경과 표시 문자를 사용합니다. 최소 창 너비 760에서는 2열, 기본 너비 960에서는 3열로 배치합니다.
- 동일한 앱 목록의 표시 템플릿만 교체해 검색·필터·알림 우선순위와 진행 중인 작업을 유지합니다. 그리드에도 진행률·오류·취소를 연결했으며, 기존 업데이트 검사는 카드 배치 순서 대신 실제 실행 버튼을 찾아 검증하도록 보완했습니다.
- Release 빌드 경고 0개·오류 0개, 설정 관련 테스트 17개와 일반/백그라운드 스모크 검사를 통과했습니다. 보기 저장·다른 설정 보존, 검색·업데이트 필터 유지, 2/3열 카드 경계와 상태 표시를 확인하고 기존 모의 업데이트·알림·일괄 업데이트 검사를 두 보기에서 수행했습니다. 별도 데이터 폴더의 실제 화면에서 커버·버전·버튼 표시와 보기 전환도 확인했습니다.

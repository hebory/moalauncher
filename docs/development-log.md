## 검증 기록 · 2026-11-07

- `dotnet test tests/MoaLauncher.Core.Tests/MoaLauncher.Core.Tests.csproj`: 44개 통과. 잘못된 체크섬, 누락된 실행 파일, ZIP 경로 탈출·심볼릭 링크·과도 압축, 취소, 기존 설치 상태 보존, HTTP 오류·캐시를 포함합니다.
- WPF Release 빌드: 경고 0, 오류 0. 실제 설치된 모아뷰 `0.1.7` 자동 탐지 확인.
- 실제 GitHub 통신: 참고 저장소의 최신 안정 릴리스 조회(200), ETag 재확인(304, 최신 상태), 허용된 리디렉션을 통한 `SHA256SUMS.txt` 다운로드, API digest와 파일 SHA-256 일치 확인. 해당 프로그램을 설치하거나 실행하지 않았습니다.
- 자체 포함 Windows x64 배포: .NET / Windows Desktop `8.0.33`, 카탈로그, 런타임 라이선스, ZIP 및 체크섬 생성.
- 초기 구현 시점에는 모아뷰 릴리스 저장소가 연결되지 않아 실제 다운로드·설치·업데이트를 검증하지 않았습니다. 후속 연결 검증은 아래에 기록합니다. GitHub Actions는 구성했으며 원격 실행은 하지 않았습니다.

제한된 개발 환경에서 testhost 프로세스 통신이 차단되어 테스트 실행은 해당 통신을 허용한 환경에서 수행했습니다. 패키지 복원에는 이미 설치된 로컬 NuGet 캐시를 사용했습니다.

## 모아뷰 기본 연결 및 설치 사전 검증 · 2026-11-07

- 기본 카탈로그와 배포본을 `hebory/moaview`에 연결했습니다. 자산 패턴은 `MoaView-*-Setup-x64.exe`, 설치 위치는 `%LOCALAPPDATA%\Programs\MoaView`입니다.
- 카탈로그·릴리스 관련 테스트 29개 통과, Release 빌드 경고 0개·오류 0개.
- 실제 코어 서비스로 기본 카탈로그를 읽고 기존 모아뷰 `0.1.7` 설치를 탐지했습니다. 실행 중인 모아뷰 프로세스는 없었습니다.
- 공개 GitHub API 결과: `GET /repos/hebory/moaview/releases?per_page=100`은 HTTP 200 / `[]`, `/releases/latest`는 HTTP 404. 코어 서비스도 ‘공개된 안정 버전을 찾을 수 없습니다’ 오류를 표시했습니다.
- 공개 릴리스가 없으므로 GitHub에서 설치 파일을 다운로드하거나 실행하지 않았습니다. 기존 설치와 사용자 데이터는 변경하지 않았습니다. 실제 설치·업데이트 검증은 릴리스 게시 후 진행해야 합니다.
- 게시 준비: 기존 로컬 `MoaView-0.1.7-Setup-x64.exe`(68,919,710바이트)의 ProductVersion과 인접 `.sha256`을 검증했습니다. SHA-256은 `DABEE6AC4ED495BF17536BE410E98BC4781391B44BC9DE0C1A21487641AD8CD6`입니다. 설치 파일·체크섬·게시 설명은 Git에서 제외된 `artifacts/moaview-verification/release-v0.1.7/`에 준비했습니다.
- 기존 설치 버전도 0.1.7이므로 v0.1.7 게시 후에는 같은 버전의 재설치를 검증할 수 있습니다. 실제 버전 상승 업데이트를 검증하려면 더 최신의 공식 릴리스 또는 별도의 구버전 테스트 환경이 필요합니다.

## 런처 디자인 개선 · 2026-11-07

- 밝은 배경과 짙은 사이드바, 블루 포인트로 공통 테마를 정리했습니다. 라이브러리는 앱 목록과 선택 앱 상세 패널을 함께 보여주며, 설치·최신 버전과 변경 사항을 바로 확인할 수 있습니다.
- 검색·필터·빈 상태 안내, 설정 토글, 프로그램 등록 폼, 버튼과 입력 필드의 스타일을 통일했습니다. 릴리스 노트의 제목·링크·코드 표시는 읽기 쉬운 일반 텍스트로 정리했습니다.
- 제목 표시줄과 창 제어 버튼을 적용하고, 현재 모니터의 작업 영역에 맞춰 최대화하도록 처리했습니다.
- Release 빌드 경고 0개·오류 0개. 분리된 검토용 데이터 폴더로 실행해 검색 결과와 초기화, 상세 정보, 설정·등록 화면, 패키지 선택 목록 표시를 확인했습니다. 기본 1320×880, 최소 1080×720, 최대화 화면과 스크롤을 점검했습니다.
- 검토 도중 공개된 모아뷰 v0.1.7 릴리스가 정상 조회되며, 기존 설치 버전 0.1.7과 변경 사항이 표시되는 것을 확인했습니다. 이번 디자인 작업에서는 모아뷰 설치나 업데이트를 실행하지 않았습니다.
- Windows x64 자체 포함 배포 ZIP과 SHA-256 파일을 새 디자인으로 다시 생성했습니다.

## 트레이 상주 및 종료 동작 · 2026-11-07

- 메인 창의 닫기 버튼은 창만 숨기고 트레이 아이콘, 주기 확인 타이머, 진행 중인 작업을 유지합니다. 트레이 아이콘 클릭 및 ‘모아 런처 열기’ 메뉴로 다시 열 수 있습니다.
- ‘종료’ 메뉴와 설정의 ‘런처 종료’는 실제 종료를 요청합니다. 설치·다운로드 작업이 진행 중이면 종료를 보류하고 창을 열어 안내합니다. Windows 로그오프/종료는 트레이 숨김으로 전환하지 않습니다.
- 동일 데이터 폴더로 재실행하면 새 프로세스는 기존 인스턴스에 활성화 이벤트를 전달하고 종료합니다. 숨겨진 창과 최소화된 창을 복원하며 정상 초기화를 반복하지 않습니다.
- 다중 크기의 모아 아이콘을 내장하고, 정상 종료 시 트레이 아이콘과 메뉴·이벤트·단일 인스턴스 리소스를 정리합니다.
- 실제 Windows 화면에서 닫기 후 창 숨김과 프로세스 유지, 재실행 후 동일 창 복원, 완전 종료 후 프로세스 종료를 확인했습니다.
- 네트워크 없는 전용 카탈로그를 사용한 Windows STA 회귀 스모크 테스트를 추가했습니다. 실제 WPF 메시지 루프에서 숨김 중 타이머 동작, 트레이 메뉴 콜백, 최소화/활성화 복원, 작업 중 종료 방지, 아이콘 해제를 검증해 통과했습니다. Windows CI에도 이 테스트를 연결했습니다.
- Release 빌드 경고 0개·오류 0개. Windows x64 자체 포함 배포 ZIP과 SHA-256 파일을 갱신했습니다.

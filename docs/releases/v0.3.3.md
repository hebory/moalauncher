## 실행 중인 앱도 종료 후 업데이트

실행 중이라는 이유로 업데이트를 바로 중단하던 동작을 개선했습니다.

- 업데이트 파일을 내려받고 검증한 뒤 대상 프로그램에 일반 종료를 요청합니다.
- 5초 뒤에도 실행 중이면 **강제 종료 후 업데이트** 또는 **취소**를 선택할 수 있습니다. 강제 종료하면 저장하지 않은 작업이 사라질 수 있으므로 작업을 먼저 저장하세요.
- 확인을 기다리는 동안 프로그램을 직접 종료해도 업데이트를 이어갑니다. 확인창에서 취소하거나 런처 창을 닫으면 해당 업데이트를 중단합니다.
- 실행 파일의 전체 경로로 대상을 확인합니다. 개별·모두·트레이 업데이트에 같은 규칙을 적용하고, 런처 자체 업데이트는 마지막에 진행합니다.

## 더 선명하고 단순해진 화면

- 왼쪽 탐색, 고정 검색 도구 모음, 반응형 그리드와 정렬된 리스트를 새 디자인으로 다듬었습니다.
- 아이콘·커버·설치 버전·상태·주요 작업을 간결하게 표시하고, 자세한 정보는 상세 화면에서 확인합니다.
- **설치됨**과 **업데이트**는 목록에서 같은 작은 배지로, 그리드에서 커버 우측 상단 배지로 표시합니다.
- 글자 크기·대비·여백·버튼·설정 스위치를 통일하고 처음 창을 열 때 표시를 보완했습니다.

개인 카탈로그·즐겨찾기·설치 상태·GitHub 인증·보기 설정을 유지합니다. 창을 닫으면 트레이에서 계속 실행되며, 창 없는 자동 시작과 공개·비공개 앱 설치도 이어서 사용할 수 있습니다.

Windows 10/11 x64용 순수 Rust 네이티브 앱입니다. 설치하려면 `MoaLauncher-0.3.3-Setup-x64.exe`, 포터블로 사용하려면 `moa-launcher-0.3.3-windows-x64.zip`을 내려받으세요.

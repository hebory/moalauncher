## 화면까지 Rust로 만든 모아 런처

모아 런처를 Rust + egui/eframe으로 전환했습니다. 화면과 작업 로직 모두 Rust로 실행하며 Tauri, React, WebView2 Runtime이나 별도 .NET 설치가 필요하지 않습니다.

- 개인 카탈로그·즐겨찾기·설치 상태·GitHub 인증을 기존 데이터 경로에서 그대로 이어받습니다.
- 한글 그리드·리스트, 검색·필터, 아이콘·커버, 설치 버전과 릴리스 상세 화면을 제공합니다.
- 공개·비공개 GitHub 앱의 설치·업데이트와 ZIP·Inno Setup·NSIS 패키지를 지원합니다.
- ‘모두 업데이트’는 일반 도구를 먼저 처리하고 런처를 마지막에 업데이트합니다. 트레이 메뉴에서도 실행할 수 있습니다.
- 창을 닫아도 트레이에서 실행합니다. Windows 자동 실행은 창을 만들지 않고 트레이에서 시작하며 열기를 선택할 때 창을 만듭니다.
- 기본 1시간의 업데이트 확인 간격과 24시간 등 여러 시간 설정, 업데이트 알림 설정을 유지합니다.
- 다운로드 SHA-256 검증, 취소, 런처 자체 업데이트와 실패 시 파일 복구를 지원합니다.

### 설치·업데이트

Windows 10/11 x64에서 `MoaLauncher-0.3.0-Setup-x64.exe`를 실행하세요. 기존 런처는 트레이 메뉴에서 종료한 뒤 설치하면 됩니다. 기존과 같은 현재 사용자 설치 경로와 제품 ID를 사용하며 개인 카탈로그·설정·인증은 유지합니다.

포터블 사용은 `moa-launcher-0.3.0-windows-x64.zip`을 별도 폴더에 풀어 실행하세요. 설치 파일과 ZIP의 SHA-256은 `SHA256SUMS.txt`에서 확인할 수 있습니다.

Rust 단위 테스트 40개, 실제 공개·비공개 다운로드와 NSIS·Inno 설치·업데이트, 자체 업데이트 성공 및 실패 복구, 창 없는 시작과 단일 인스턴스 활성화를 검증했습니다. 실제 Windows 로그인 전체 과정과 새 릴리스 알림 클릭은 자동화 시험 범위에 포함하지 않았습니다.

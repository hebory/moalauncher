## 더 선명하고 단순해진 모아 런처

순수 Rust 화면을 일관된 디자인으로 다듬었습니다.

- 왼쪽 탐색 영역에서 전체 프로그램·즐겨찾기·설치됨·업데이트를 빠르게 이동합니다.
- 고정 검색 도구 모음, 반응형 그리드와 정렬된 리스트로 필요한 도구를 찾습니다.
- 아이콘·커버, 설치 버전, 상태와 실행 버튼을 간결한 카드에 표시하며 릴리스 노트와 관리 항목은 상세 화면에서 확인합니다.
- ‘설치됨’과 ‘업데이트’는 목록에서 같은 작은 배지로, 그리드에서 커버 우측 상단 배지로 표시합니다. 상태는 색상으로 구분하며 오류·작업 중 상태는 우선 표시합니다.
- 한글 글자 크기와 굵기, 대비·여백·벡터 아이콘·버튼·토글을 통일했습니다.
- 설정을 시작·업데이트·GitHub 연결·개인 데이터로 나누고 설명과 스위치를 정렬했습니다.
- 처음 창을 열 때 화면 표시를 다시 갱신하도록 보완했습니다.

개인 카탈로그·즐겨찾기·설치 상태·GitHub 인증·보기 설정을 유지합니다. 트레이, 창 없는 자동 시작, 공개·비공개 앱 설치와 모두 업데이트의 동작도 그대로 사용할 수 있습니다.
